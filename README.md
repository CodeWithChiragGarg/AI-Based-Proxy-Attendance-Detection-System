AI-Based Proxy Attendance Detection System

Machine Learning-based attendance monitoring system developed to detect suspicious attendance behavior and proxy activities using anomaly detection techniques.

✨ Features
- Proxy attendance detection
- Suspicious attendance pattern analysis
- Anomaly detection using Isolation Forest
- Attendance preprocessing and cleaning
- Automated suspicious activity identification
- Data visualization and analysis

🛠️ Tech Stack
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

📊 ML Algorithm Used
- Isolation Forest (Unsupervised Learning)

🎯 Objective
To identify abnormal attendance behavior and reduce proxy attendance in educational institutions using Machine Learning.

📈 Key Concepts
- Unsupervised Learning
- Anomaly Detection
- Attendance Pattern Analysis
- Feature Engineering
